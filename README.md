# PSP-Texture-Pack-JP

PPSSPP（PSPエミュレータ）向けの**高画質（HD）日本語テキスト・UI専用テクスチャパック集**です。

海外有志によって作成されたHDリマスターパックを導入した際に、ゲーム内のメニューやシステムメッセージが強制的に「英語化」されてしまうのを防ぎ、**日本語フォントの視認性を損なわず4倍解像度へ高精細化**することを目的としています。

## 🎮 対応タイトル一覧

ISO ID（ゲームID）ごとにディレクトリを分けて管理しています。

| ゲームID | タイトル | 併用推奨（オリジナルHDパック） | 備考 |
| :--- | :--- | :--- | :--- |
| `NPJH50107`<br>`ULJS00250` | 機動戦士ガンダム<br>ガンダムVS.ガンダム NEXT PLUS | [Saramagrean氏版](https://github.com/Saramagrean/Gundam-Next-Plus---Texture-Pack/tree/master/Text) | UI・メニュー・システムテキスト日本語HD化 |


> **Note:** UMD版とダウンロード（DL）版でゲームIDが異なる場合でも、内部のテクスチャハッシュ値は共通です。ご自身の環境に合わせてフォルダ名をリネームしてご使用ください。

## 🛠️ 導入方法

### 単体で使用する場合（日本語UIのみ高画質化）
1. 本リポジトリの `PSP` フォルダをダウンロードします。
2. お使いの端末（PC / Android / iOS）のPPSSPPデータ保存先にある `PSP` フォルダへ上書きコピーします。
   * **Windows:** `PPSSPPインストールフォルダ/memstick/PSP/TEXTURES/[ゲームID]/`
   * **Android:** `内部ストレージ/PSP/TEXTURES/[ゲームID]/`
   * **iOS:** `ファイルアプリ > このiPhone内 > PPSSPP > PSP > TEXTURES > [ゲームID]/`
3. PPSSPPを起動し、**設定 ＞ ツール ＞ 開発者向けツール ＞ テクスチャを置き換える** にチェックを入れます。

### 海外製HDパックと併用する場合（英語化の解除・日本語戻し）
すでに海外製の総合HDテクスチャパック（機体や背景のHD化パックなど）を導入している場合は、以下の手順で文字だけを日本語に戻すことができます。

1. 導入済みの海外製テクスチャパック内（`PSP/TEXTURES/[ゲームID]/`）にある、英語化用のテキストフォルダ（`Text` や `GUI` など）を削除またはリネームして無効化します。
   * *(※`textures.ini` 内に直接テキストの置換コードが書かれている場合は、該当行の先頭に `#` をつけてコメントアウトしてください)*
2. 本リポジトリのテクスチャファイル（PNG）を同じ `[ゲームID]` フォルダ内に配置します。
   * *(※`textures.ini` が競合する場合は、本リポジトリのフォルダ構成に合わせて統合してください)*
